# Keyword Plan (Retail)

**Important:** no search-volume tool was available while building this, so priorities below are based on commercial intent and competition, not measured volume. Before investing in content, validate each row in Google Keyword Planner (free with a Google Ads account) and, after launch, in Google Search Console.

Priority: **P1** = build/optimise first, **P2** = next, **P3** = later.
Status: **Live** = page exists and targets it, **Planned** = page to be created.

## 5. Local (only if you choose to show a city)

If the business wants local walk-in or same-city delivery traffic, add the city in `site.ts`, create a Google Business Profile, and target one page:

| Keyword | URL |
| --- | --- |
| imitation jewellery shop in [city] | `/imitation-jewellery-[city]/` |

Do not create multiple city pages without a real presence in those cities.

## Rules used

1. One primary keyword per URL. No two pages compete for the same term.
2. Every blog post links to at least two commercial pages, with descriptive anchor text.
3. Category and collection pages carry unique copy below the grid, not above it, so products stay in the first screen.
4. Filters never create indexable URLs (canonical always points at the clean path).
